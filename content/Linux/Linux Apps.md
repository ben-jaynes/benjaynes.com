On this page I will have a list of some of the most important applications that I like to use on linux and would recommend to others. I am currently using Fedora with Niri as my window manager so keep that in mind. Most of these apps will probably work with other distros, desktop environments or potentially operating systems.

## Currently Using
- Browser: [Helium](https://helium.computer/)
- Terminal Emulator: [Alacritty](https://alacritty.org/)
- Notes: [Obsidian](https://obsidian.md/)
- Desktop Shell: [Dank Material Shell](https://github.com/AvengeMedia/DankMaterialShell)
- IDE: [Visual Studio Code](https://code.visualstudio.com/)
- Todos / Task Management: [Planify](https://useplanify.com/)
- Password Manager: [Bitwarden](https://bitwarden.com/help/getting-started-browserext/) (browser extension)
- Calendar: [Gnome Calendar](https://apps.gnome.org/Calendar/)
	- I self-host [Radicale](https://radicale.org/v3.html) to manage and sync my calendars and todos
